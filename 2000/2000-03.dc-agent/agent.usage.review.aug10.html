Title: DC Agents Working Group Review of Creator/Contributor/Publisher Qualifier Usage

Date: 1999-08-10

Status: None

This report is a summary from implementers for recommendations concerning qualifier semantics for CREATOR, CONTRIBUTOR and PUBLISHER that have been found to be useful in existing applications, and judged to be potentially useful for a broad range of Dublin Core applications (and hence, important to promote interoperability).

The CURRENT version of this report lists the qualifiers of significant implementations of Dublin Core. Subsequent versions will present a consolidated single list.
