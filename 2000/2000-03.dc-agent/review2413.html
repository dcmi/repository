Title: DC Agents Working Group Review of RFC2413

Date: 1999-03-03

Status: Working Group Recommendation

Proposed new definitions for the Dublin Core metadata elements: Creator, Contributor, and Publisher. The main changes from the definitions in RFC2413 are:
  • Adoption of ISO 11179 representation for metadata elements
  • Consistent and broader Definitions across all three elements for more flexibility
  • Application of the metadata elements described in the Comment
  • Removal of examples of types of Agents
  • Removal of "secondary" dependency between Creator and Contributor
  • "Author or Creator" Name changed to "Creator"
  • "Other Contributor" Name changed to "Contributor"

Element: Creator

RFC2413 Definition
   Author or Creator                 Label: "Creator"

   The person or organization primarily responsible for creating the
   intellectual content of the resource.  For example, authors in the
   case of written documents, artists, photographers, or illustrators in
   the case of visual resources.
Proposed New Definition
  Name:        Creator
  Identifier:  Creator
  Definition:  An entity primarily responsible for the intellectual
               content of the resource
  Obligation:  Optional
  Datatype:    Character String
  Maximum
   Occurrence: Unlimited
  Comment:     Examples of a Creator include a person, an organisation,
               an object, or a service.
               Typically, the name of the Creator should be used to
               indicate the entity.

Element: Contributor

RFC2413 Definition
   Other Contributor                 Label: "Contributor"

   A person or organization not specified in a Creator element who has
   made significant intellectual contributions to the resource but whose
   contribution is secondary to any person or organization specified in
   a Creator element (for example, editor, transcriber, and
   illustrator).
Proposed New Definition
  Name:        Contributor
  Identifier:  Contributor
  Definition:  An entity responsible for contributions to the intellectual
               content of the resource
  Obligation:  Optional
  Datatype:    Character String
  Maximum
   Occurrence: Unlimited
  Comment:     Examples of a Contributor include a person, an organisation,
               an object, or a service.
               Typically, the name of the Contributor should be used to
               indicate the entity.

Element: Publisher

RFC2413 Definition
   Publisher                         Label: "Publisher"

   The entity responsible for making the resource available in its
   present form, such as a publishing house, a university department, or
   a corporate entity.
Proposed New Definition
  Name:        Publisher
  Identifier:  Publisher
  Definition:  An entity responsible for making the resource available
  Obligation:  Optional
  Datatype:    Character String
  Maximum
   Occurrence: Unlimited
  Comment:     Examples of a Publisher include a person, an organisation,
               an object, or a service.
               Typically, the name of the Publisher should be used to
               indicate the entity.
